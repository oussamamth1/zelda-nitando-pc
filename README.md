# zelda-nitando-pc

Personal mods and config files for my Ship of Harkinian (OoT PC port) setup.

This repo tracks only my own mods and configuration — it does not include the
game ROM, compiled binaries, extracted assets, saves, or logs, since those
are either copyrighted or machine-generated/personal and don't belong in
version control.

## Contents

- `mods/` — custom mod files
- `shipofharkinian.json` — main config
- `speedrun_settings_backup.json` — speedrun settings backup
- `imgui.ini` — UI layout
- `SoHTimeSplitData.json` — time split data
